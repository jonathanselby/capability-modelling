# Bad First Draft — Sydney Water

A structure-first pass over public material could produce:

```text
Water Treatment Plants
Wastewater Treatment Plants
Recycled Water Network
Stormwater Assets
Pumping Stations
Reservoirs
WaterFix
Future Ready
Upper South Creek Project
Customer Billing
Water Quality Testing
Supplier Tenders
```

## Why this is weak

| Label | Problem |
|---|---|
| Water Treatment Plants | facility class |
| Wastewater Treatment Plants | facility class |
| Recycled Water Network | physical network/asset view |
| Stormwater Assets | asset class |
| Pumping Stations | facility class |
| Reservoirs | asset class |
| WaterFix | named programme/service |
| Future Ready | transformation programme |
| Upper South Creek Project | project |
| Customer Billing | narrow process/activity |
| Water Quality Testing | activity/process |
| Supplier Tenders | sourcing process/artifact |

The source nouns are useful evidence about the operating environment, but they are not a stable capability hierarchy.
