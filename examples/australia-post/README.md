# Australia Post — Public-Source Worked Example

This example applies the capability-modelling method to public Australia Post material.

It is **not** Australia Post's official capability model.

## Modelling question

Can public evidence about a very large national logistics, delivery, retail-access and community-service organisation be translated into enduring capabilities without copying channels, facilities, programmes or products into the model?

## Source basis

Official Australia Post sources retrieved 15 October 2026:

- About us: https://auspost.com.au/about-us
- Fast facts: https://auspost.com.au/about-us/news-media/fast-facts-about-australia-post
- Customer Commitment and Service Charter: https://auspost.com.au/about-us/corporate-information/our-organisation/customer-commitment-and-service-charter
- Australia Post Annual Report 2025: https://auspost.com.au/content/dam/auspost_corp/media/documents/2025-australia-post-annual-report.pdf
