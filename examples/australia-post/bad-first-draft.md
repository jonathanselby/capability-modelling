# Bad First Draft — Australia Post

A first pass built by copying visible nouns from public material could look plausible:

```text
Post Offices
Parcel Lockers
Delivery Vehicles
MyPost Business
Letters Business
Parcels Business
Retail Network
Delivery Network
Digital Channels
International Parcels
Network Modernisation
Community Service Obligations
```

## Why this is weak

| Label | Problem |
|---|---|
| Post Offices | facility/channel |
| Parcel Lockers | technology/facility |
| Delivery Vehicles | asset class |
| MyPost Business | named product/service |
| Letters Business | organisational/product-line ambiguity |
| Parcels Business | organisational/product-line ambiguity |
| Retail Network | physical operating structure |
| Delivery Network | physical operating structure |
| Digital Channels | channel/implementation |
| International Parcels | product/market slice rather than clearly bounded ability |
| Network Modernisation | temporary change activity |
| Community Service Obligations | obligation/outcome, not itself an ability |

The labels contain useful evidence, but they mix channels, assets, products, structures, obligations and change with capabilities.
